1. 产品命名建议 Naming

均为个人工具属性，无社交/品牌负担，域名与商店上架阻力小。

① 一记 推荐

读音 yī jì。Slogan：「一记就好」。直击「一键记一笔」核心动作，三步内完成，记忆成本低，天然适配桌面 Widget 名称。中文商店搜索「一记」竞争小。

② 钱迹 备选

读音 qián jì。钱的轨迹/痕迹，强调「深度洞察」——流水、趋势、净资产都是「迹」。偏分析向，适合后期资产管理总览卖点。

③ 简记 备选

读音 jiǎn jì。极简 + 记账，表意直白，小白友好。缺点是通用词、商标防御性弱，可作为副标题或功能区命名。

推荐结论：主名用 一记，副标题「极简记账 · 你的私人财务台」。上线后用「一记 · 极简记账」做 ASO 关键词覆盖。

4. 各功能模块详细 PRD Module Specs

4.1 第一层 · 核心基础功能（MVP）

① 快速记账

  • 字段：金额、type(支出/收入/转账)、category_id、account_id、to_account_id(转账)、note、transaction_date、tags。
  • 交互：底部悬浮「＋」→ 弹出金额计算器键盘（默认 0.00，支持 + - × ÷ 与退格）→ 选分类+账户（卡片式，带图标与颜色）→ 点「保存」。备注可选，点开抽屉输入。
  • 计算器规则：连续运算（如 12.5+3.5=16）；结果自动千分位；最多 2 位小数；除零提示「无效运算」。
  • 智能默认：记住上次选择的分类/账户，下次预填；长按「＋」可语音记账（第三层）。
  • 异常：金额为 0 或空 → 禁用保存并抖动提示；日期选未来 → 允许（待入账），但统计按月归集到实际日期；保存失败 → 本地重试队列 + Toast「稍后自动保存」。

② 收支分类体系

  • 预设支出：餐饮、交通、购物、居住、娱乐、医疗、教育、人情、通讯、日用（各带默认图标+颜色）。
  • 预设收入：工资、奖金、理财收益、兼职、红包、报销。
  • 自定义：名称 + 图标(内置图标库) + 颜色(调色板)；支持二级分类（parent_id）。
  • 管理：拖拽排序、隐藏（隐藏后不出现在快捷选择但历史保留）、删除（软删除，若已有交易则提示「将归为「未分类」」）。
  • 异常：删除系统预设分类 → 二次确认；重名 → 允许（同色不同图标不冲突）。

③ 多账户管理

  • 类型：现金、储蓄卡、信用卡、支付宝、微信、投资账户、负债账户。
  • 余额联动：每笔交易按 type 增减对应账户余额（转账：from 减、to 加，净额不变）；余额=初始余额+Σ流水，实时重算。
  • 信用卡：账单日、还款日、额度；还款日临近 Toast 提醒；已用额度=额度-可用。
  • 转账：独立 type=transfer，不计入收支汇总，仅影响两账户余额。
  • 异常：删除仍有余额的账户 → 提示先转账清零或归档；余额为负 → 红色警示（信用卡/负债允许负）。

④ 日历与流水视图

  • 日历：月视图，每日格显示收支小计与一个点（有记录才亮）；点日 → 下钻当日明细。
  • 流水：按 transaction_date 倒序；日/周/月分段头显示区间汇总；下拉刷新、上拉加载（分页 30 条）。
  • 手势：左滑删除、右滑编辑；空状态显示「这天还没有记录，点＋记一笔」引导。
  • 异常：加载失败 → 展示缓存数据并标注「离线」；刷新冲突 → 以本地 updated_at 最新为准。

⑤ 基础统计报表

  • 月度汇总：收入、支出、结余（=收入-支出，转账不计入）。
  • 饼图：支出分类占比（点分类看金额/笔数）。
  • 折线：近 12 月收支趋势（双线：收入绿、支出红，遵循 A 股配色惯例）。
  • 维度：按月/按年切换；年视图聚合 12 月。
  • 异常：无数据 → 空图表占位「暂无数据，先记几笔吧」。

4.2 第二层 · 进阶功能

① 预算管理

  • 月度总预算 + 分类预算；进度条（已用/剩余/超支三色）；阈值 80% 黄、100% 红推送预警；预算不随账本隔离可独立设。

② 周期性账单

  • 固定收/支按 日/周/月/年 自动生成；可「自动入账」或「提醒确认」；next_execute_date 到期引擎在凌晨跑；手动补生成历史缺口。

③ 搜索与筛选

  • 关键词搜 note；金额 大于/小于/区间；分类+账户+日期组合；结果批量编辑/删除（二次确认，软删）。

④ 数据导入导出

  • 导出 CSV / Excel；CSV 导入（字段映射向导）；微信/支付宝账单 PDF/CSV 解析（关键字识别商户+金额+分类推测）。

⑤ 标签系统

  • 记录可打多标签（可报销/旅行/装修）；标签筛选与统计；标签色自定义。

4.3 第三层 · 差异化亮点

① 智能快捷记账

  • 桌面 Widget（iOS/Android 原生桥接 Flutter）、通知栏快捷入口、语音记账（ASR 解析「午饭 35」→ 金额 35 + 餐饮）。

② 资产管理总览

  • 净资产=总资产-总负债仪表盘；资产变化趋势；各账户占比环图。

③ 多账本

  • 独立账本（日常/旅行/项目/家庭）；数据隔离（book_id 分片）；切换器在「我的」；各账本独立统计与预算。

④ 数据可视化增强

  • 消费热力图（日历色块）、同比/环比、自定义报表（维度交叉：分类×账户×时间）。

⑤ 数据安全与隐私

  • APP 锁（密码/PIN/生物识别）；本地 SQLite 加密（SQLCipher）；云端备份 WebDAV/iCloud/Google Drive（可选）；一键导出+注销清空。

6. MVP 功能范围与迭代路线图 Scope & Roadmap

MVP（必须上线）

快速记账(计算器)分类体系多账户+转账日历/流水基础统计本地加密存储深色模式

MVP 不做：预算、周期账单、云同步、Widget、多账本、语音。先验证「3 步记账」留存，再迭代。

迭代路线图

v1.0 · MVP
第 1–6 周
Flutter 骨架 + Drift(SQLite/SQLCipher) + 记账/分类/账户/流水/统计 + 离线优先落库。目标：连续 7 天记账成功率 > 80%。
v1.1 · 进阶
第 7–11 周
预算、周期账单、搜索筛选、标签、CSV/Excel 导入导出（含微信/支付宝账单解析）。
v2.0 · 亮点
第 12–16 周
桌面 Widget + 通知栏快捷、语音记账、资产管理总览（净资产）、多账本、消费热力图/同比环比、APP 锁与生物识别。
v2.1 · 同步
第 17–20 周
WebDAV / iCloud / Google Drive 备份恢复；冲突合并上线；一键导出+注销。仅个人用可后做。

技术栈建议

  • 前端：Flutter 3.x（单代码库 iOS/Android）；状态管理 Riverpod；本地 DB drift + sqlcipher 加密。
  • 图表：fl_chart（饼/折线/热力）；图标 flutter_iconpicker。
  • 同步：本地队列 + 幂等上传；WebDAV 用 webdav_client，iCloud 走 native 桥接。
  • 生物识别：local_auth；APP 锁 flutter_secure_storage 存密钥。

7. UI 风格建议 Visual Style

设计原则

  • 极简、信息密度适中；主色代表「增长/健康」，金额红涨绿（A 股惯例，支出红、收入绿）。
  • 高频操作区（记一笔、保存）落在屏幕下半区，单手可达；底部 Tab 5 个，居中悬浮「＋」。
  • 圆角 14px、轻投影、留白充足；空状态必有引导插画+行动按钮。

字体与图标

  • 字体：中文 苹方 / 思源黑体；数字用等宽 Roboto Mono（金额对齐）。正文 15px，金额 22px 半粗。
  • 图标：线性+轻微填充（如 Material Symbols / Flutter Icon），2px 描边、圆角；分类图标可换色。
  • 深色模式：跟随系统；深色背景 #121212、卡片 #1e1e1e、主色提亮为 #3a9d63；金额红绿在深色下提高明度保证对比度。
金额格式统一：千分位 + 2 位小数，如 ¥ 12,345.67；负值显示 -¥ 1,200.00。空状态模板：「这里还空空的～ 点下方按钮开始」+ 插画。
