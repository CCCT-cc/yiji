# 一记 · 微信小程序 部署说明

原生微信小程序工程（WXML/WXSS/JS），数据全部存本机 `wx.storage`，**不联网、不上传任何服务器、不收集隐私**。

## 一、你本人要准备的东西（我代不了）

1. **微信公众平台账号** — 前往 https://mp.weixin.qq.com 注册。
   - 个人号：免费，但「记账 / 财务」类目个人主体**大概率被审核打回**（微信对 financial 类目审核严）。
   - 企业号：用营业执照注册，类目更稳，提审通过率高。
   - 👉 强烈建议用**企业/个体工商户**主体；纯个人想上架记账类目风险高。
2. **小程序 AppID** — 注册后在「开发管理 → 开发设置」里拿到。
3. **微信开发者工具** — 官网下载安装（稳定版即可）。

## 二、导入与替换 AppID

1. 打开「微信开发者工具」→ 导入项目。
2. 目录选本工程文件夹 `yiji-mp/`。
3. AppID 一栏：先选「测试号 / 游客模式」可直接预览；上传提审前必须换成**你自己的 AppID**。
4. 换 AppID：编辑 `project.config.json` 第 46 行 `"appid": "touristappid"` → 改成你的 AppID，或在开发者工具顶部直接修改并保存。

```json
"appid": "wx你的真实appid"
```

## 三、本地预览

导入后点「编译」即可在模拟器看到界面。功能：
- 首页：净资产合计 + **按账户分列余额** + 本月收支
- 记一笔：选账户/分类/日期/备注，存本机
- 流水：按日分组、可删
- 统计：本月分类支出占比
- 我的：账户管理 / 分类管理 / 账本管理 / CSV 备份到剪贴板 / 清空

> 数据在模拟器和真机都只存在本机，卸载小程序即清除（微信机制如此）。备份请用「我的 → 导出备份」复制到备忘录/文件传输助手。

## 四、上传与提审

1. 开发者工具点「上传」→ 填版本号（如 `1.0.0`）和备注。
2. 到 mp.weixin.qq.com「版本管理」把上传的版本**提交审核**。
3. 审核要填：
   - **类目**：工具 → 记账 / 或 财务 → 记账（企业号更稳）
   - **用户隐私保护指引**：本 App 不收集任何个人信息、不使用任何网络接口。在指引里勾选「不收集用户信息」并说明仅本地存储即可。可参考 `yiji-cap/隐私政策.html` 的口径。
   - **服务类目资质**：若选财务类目，可能要软著/相关资质（企业号按提示上传）。

## 五、常见被拒原因与规避

- 个人主体 + 记账类目 → 被打回。✅ 用企业号。
- 页面有「分享到朋友圈/群」诱导 → 被打回。本工程未加诱导分享。
- 声称"云端同步/备份"却无服务器 → 被打回。本工程明确**只本地存储**，文案不要写"云同步"。
- 隐私指引与实际不符 → 被打回。如实填"不收集用户信息"。

## 六、文件结构

```
yiji-mp/
├── app.js / app.json / app.wxss      # 全局：入口、页面注册、tabBar、公共样式
├── project.config.json               # 工程配置（记得换 appid）
├── sitemap.json
├── utils/
│   ├── store.js                      # 数据层（账本/账户/交易/分类 + 净资产/月度/分类统计）
│   └── util.js                       # 日期与金额格式化
└── pages/
    ├── home/        # 首页（净资产分列）
    ├── add/         # 记一笔
    ├── list/        # 流水
    ├── stats/       # 统计
    ├── mine/        # 我的
    ├── accounts/    # 账户管理
    ├── categories/  # 分类管理
    └── ledgers/     # 账本管理（多账本切换）
```
