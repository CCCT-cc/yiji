# 一记 · 极简记账（桌面版）

一款**纯本地、离线可用、数据不出设备**的极简记账工具。一个字就能记一笔，支持多账户、分类、预算提醒、定期账单自动补记，以及**完整账本备份/恢复**——再也不怕清档、重装、误删导致数据丢失。

基于 Electron 封装，核心账本逻辑是一个零依赖的纯前端应用（`web/` 目录），可单独部署为网页，也可打包成桌面 App。

## 功能特性

- 📝 **极简录入**：首页一键记支出/收入/转账，支持语音（Web Speech）速记。
- 💰 **多账户 & 净资产**：银行卡、钱包、理财账户分别记账，自动算净资产。
- 🏷️ **分类 / 预算**：自定义分类，超预算温和提醒。
- 🔁 **定期账单**：订阅、房租等可设自动补记。
- 📊 **统计洞察**：按月/按分类的收支趋势。
- 💾 **完整备份 / 恢复（数据安全核心）**：
  - 每次保存自动在本地留一份 `auto_latest.json` 兜底备份；
  - 「我的 → 完整备份（JSON）」可导出全部账本为文件；
  - 「我的 → 从备份恢复（JSON）」一键合并回当前账本；
  - 桌面版备份存于 `userData/backups/`，独立于浏览器存储，**清档 / 重装都不丢**；
  - App 启动时若检测到本地存储异常，会自动从备份自愈，并提示用户。

## 快速开始（开发 / 使用）

```bash
# 1. 安装依赖
npm install

# 2. 以桌面应用方式启动（开发调试）
npm start
```

> 首次使用 `npm install` 会下载 Electron（约 200MB+），请耐心等待。

## 打包成可分发的桌面应用

```bash
npm run pack
```

打包产物在 `dist/一记-win32-x64/`，生成后双击 `一记.exe` 即可使用（普通目录部署，无需安装器）。

## 作为网页部署

`web/` 目录是一个独立的纯前端应用，可直接托管到任意静态服务器 / GitHub Pages，无需后端。

## 数据存在哪里？

- 桌面版：浏览器 `localStorage`（Electron `file://` 源），备份在 `%APPDATA%/yiji-desktop/backups/`。
- 网页版：部署域名的 `localStorage`，备份退化为本地下载文件。
- **所有数据仅存于你本机，不上传任何服务器**；可选的 WebDAV 同步也由你自己的服务器承载。

## 目录结构

```
yiji-desktop/
├── main.js          # Electron 主进程（窗口 / 托盘 / 备份 IPC）
├── preload.js       # 渲染进程 ↔ 主进程 安全桥（contextIsolation）
├── web/             # 账本核心（纯前端，零依赖）
│   ├── index.html
│   ├── app.js       # 全部账本逻辑 / 备份恢复 / 自愈加载
│   └── style.css
├── package.json
└── .gitignore
```
