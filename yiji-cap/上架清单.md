## 三、国内合规硬性材料 ❗
1. **App 备案（工信部）**：2023 年起所有上架 App 须完成 App 备案，绑定到你有 **ICP 备案的域名**。
   - 你需要：一个自己名下的域名 + 该域名的 ICP 备案（国内服务器/接入商处办理）。
   - 备案时填应用名称、包名 `com.yiji.app`、签名证书 MD5/SHA1（从 keystore 取，见下）。
2. **软件著作权（软著）**：华为、应用宝等多数商店对企业开发者或特定类目要求软著。个人开发者部分商店可先上架后补，但建议准备。
   - 可自行在中国版权保护中心申请（约 1–2 个月），或找代理加急。
3. **隐私政策链接**：把本目录 `隐私政策.html` 托管到你的备案域名下（如 `https://你的域名/privacy.html`），上架时填写该 URL。
4. **权限说明**：本 App 仅「存储 + 网络」权限，上架时如实填写，不勾选无关权限。

## 四、构建与签名（产出商店包）
### 方式 A：我在此环境构建（需装 Android SDK，可能较大/受网络限制）
- 装 Android SDK（cmdline-tools + platform 34 + build-tools）+ 兼容 JDK 21
- 配置 `yiji-cap/android/` 用 `yiji-release.keystore` 签名
- `gradlew assembleRelease` / `bundleRelease` 产出 `app-release.apk` / `app-release.aab`

### 方式 B：你在本机用 Android Studio 构建（更稳）
1. 安装 Android Studio（含 SDK）
2. 打开 `yiji-cap/android/` 目录
3. Build → Generate Signed Bundle / APK，选 `yiji-release.keystore`，别名 `yiji`，填 KEYSTORE_INFO.txt 里的密码
4. 华为/小米等大多收 **APK**（部分收 AAB）；应用宝收 APK

### 取签名指纹（备案用）
```
keytool -list -v -keystore yiji-release.keystore -alias yiji
```
输出中的 MD5 / SHA1 / SHA256 即为备案填写的证书指纹。

**本密钥实际指纹（直接复制填写，密钥算法 SHA384withRSA，JDK21 不显示 MD5，MD5 由 APK 证书提取）：**

> 注：大多数商店在上传 APK/AAB 后会**自动提取**签名，无需手填；仅个别表单要求手填时粘贴上面即可。
